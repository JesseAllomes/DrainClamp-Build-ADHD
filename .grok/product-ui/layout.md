waiting-on-you list).

Let the board decide) and a "guess" tag when inferred; mini stats; completed banner with Reopen;
What it achieves; Time and cost; Next step with Add update / + Add task; activity + recent updates;

(chunks, tokens, errors, features, safeguards).

Phone (<1000px): one column, list below the overview, hidden on a project page.
