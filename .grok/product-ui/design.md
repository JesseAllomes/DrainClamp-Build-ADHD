# Design: DrainClamp board (locked round 6, 2026-09-29)

Brief (user): sleek and corporate, Linear-style, dark, calm and airy, graphs and metrics, no odd fonts.
Type pair: Inter for everything; numbers tabular.
Signature: the value layer. Before -> after per run x runs a year = hours and dollars, and a payback
chart where cumulative value crosses build cost. Build cost is your time only (min(gap, 10 min) per
prompt across Claude, Codex and Grok); agent time is shown, never billed.
Risk spent: none on chrome; density of real figures instead of decoration.
Charts: 4px rounded bar ends on a baseline, 2px lines, hairline grids, hover tooltips on every mark,
legend for two series, single series named by its title. Status split is a 2px-gapped stacked bar.
Empty states say what to do next (Measure now, Set your hourly rate, How long did this take by hand?).
Sections with no data are not drawn.
